# Roadmap and release gates

0.1.0 is a bounded pilot, not proof of growth effectiveness.

Before 1.0:

- Run a permissioned pilot on a real account for 8 weeks; report usefulness,
  voice fidelity and factual safety, not a fake score.
- Re-check the evidence register against the algorithm repo at least every
  60 days and on each notable repo update.
- Verify current subscription tiers and which analytics fields each shows.
- Test plugin installation on intended hosts.

Autonomous posting, scheduling, scraping, mass outreach and ranking
predictions are not roadmap commitments.
