# Audit, outliers, and 5 more versions

Definitions and outlier thresholds are in the [metrics](metrics.md)
reference. This file covers what to do with the results.

## Weekly audit output
```
Window: <dates, timezone>
Posts: <n original>, replies: <rough n>
Baseline: median impressions <x>, median replies <y> (last 20, target excluded)
Top 3: <post, metric, one-line hypothesis>
Outliers (3x+): <post, multiple, hypothesis>
Watch (2x to 3x): <post>
Bottom 2: <post, likely cause>
Mix: thought <n> / two-step <n> / personal <n>
Funnel: reach <n> / trust <n> / sales <n> (vs the user's weights)
Conversion: <posts that drove profile visits, link clicks, DMs (user-reported) and follows, by topic, format and stage>
CTA check: <soft-CTA posts, what they drove, any CTA the context doesn't allow>
Limits: <missing fields, small baseline, attribution caveats>
Next: <5 more versions plan, rotation change>
```

## Make 5 more versions (Ryan: "When something pops, make 5 more versions")
For each outlier, draft five, spread over the next 2 to 3 weeks:
1. **Same idea, new hook type** (a bold claim becomes a question).
2. **Same hook shape, new idea** in the same story chapter.
3. **Go deeper:** long post or Article that expands it.
4. **Flip the mix:** thought becomes personal (where the user lived it) or
   two-step (only with a real result).
5. **Answer the best reply** it got, as its own post.

Don't repost the same text. X's Original Content Rewards terms and the
author-diversity decay both work against copies.

## Monthly
Top 5 posts by replies and profile visits; which mix, funnel stage and hook
type won; which posts converted (not just reached); shift the rotation; refresh the pinned post if an outlier explains the user better.
