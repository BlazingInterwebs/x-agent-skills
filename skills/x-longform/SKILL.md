# X long posts, threads and Articles

Read [runtime](references/runtime.md), [surfaces](references/surfaces.md) and
[longform modes](references/longform-modes.md). Use [growth](references/growth.md)
for story chapters and [privacy](references/privacy.md) for client material.

## Choose the format

Confirm the idea needs length. A long post keeps all engagement on one item.
A thread fits separable steps where each post stands alone. An Article fits a
deep piece tied to a story chapter or a long video. Check the user has the
subscription a format needs; don't assume.

## Write

The opening (or title) is a clear promise with no confusion. Make it
scannable: short paragraphs, line breaks, lists where they help. Curiosity
gaps pay off inside the piece, never "more in the replies." Links go in the
body with context about what's behind them.

## Deliver

Return the draft, the chosen format and why, an alternate opening, and
anything the user must confirm. For Articles, add a one-line cover image
brief. Route a short version to `x-post` or reuse plans to `x-repurpose`.
