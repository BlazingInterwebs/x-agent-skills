# X long posts, threads and Articles

Read [runtime](references/runtime.md), [surfaces](references/surfaces.md) and
[longform modes](references/longform-modes.md). Use [growth](references/growth.md)
for story chapters and [privacy](references/privacy.md) for client material.

## Choose the format

Confirm the idea needs length. A long post keeps all engagement on one item.
A thread fits separable steps where each post stands alone. An Article fits a
deep piece tied to a story chapter, a long video, a process the user runs, or
an asset they already have. Check the user has the subscription a format
needs; don't assume. For an Article, plan the packaging (banner, title,
intro) before writing, per the reference; if it can't be made clickable,
say so.

## Write

The opening (or title) is a clear promise with no confusion. Make it
scannable: short paragraphs, line breaks, lists where they help. Curiosity
gaps pay off inside the piece, never "more in the replies." Place links per
the shared link guidance and the user's link placement, always with context
about what's behind them. End an Article with one CTA to a real `{{CTA}}`.

## Deliver

Return the draft, the chosen format and why, an alternate opening, and
anything the user must confirm. For Articles, add the packaging brief
(banner, title, intro, each with its one job), the closing CTA, and 2 to 3
quote-post angles for the following weeks. Route a short version or the
quote posts to `x-post` and reuse plans to `x-repurpose`.
