# X planning

Read [runtime](references/runtime.md), [growth](references/growth.md),
[surfaces](references/surfaces.md) and [planning](references/planning.md).

Plan from the user's real time budget, audience location, mix and pillars.
If analytics are absent, label the plan a starting hypothesis. Don't claim a
universal best time. Reserve time for replies; don't claim a ritual causes
reach.

Return the daily blocks, the weekly rotation with format defaults, the
posting slot with time zones written out, and the review cadence. Route
drafts to `x-post` or `x-longform` and results to `x-audit`. Never put
drafts into a tool that posts.
