# Post modes, hooks and packaging

## Mix modes

| Mode | Shape | Watch for |
| --- | --- | --- |
| **Thought** | Observation or real question, then one line that makes it concrete | Engagement bait ("Agree?"), questions the user doesn't care about |
| **Two-step** | Line 1 a real `{{RESULT}}` in plain words; line 2 a quiet "who's next" | Invented or uncleared results, hype, a hard pitch |
| **Personal** | A true moment from life or work, told plainly | Bow-tied lessons, private details the user didn't supply |
| **Quote post** | Someone else's post plus a real addition | Dunking, adding nothing |

Use the user's mix weights from context; a working default is about 40%
thought, 30% two-step, 30% personal.

## The five hook types (from Ryan's "Distribution 101")

| Type | What it does | Example shape |
| --- | --- | --- |
| **Bold claim** | States a strong, defensible position | "Most teams don't have a traffic problem first." |
| **Callout** | Names exactly who it's for | "Solo consultants still sending every follow-up by hand:" |
| **Curiosity gap** | Opens a loop the body closes | "There's one question I ask before I build anything." |
| **Clear outcome** | Says what the reader gets | "How to take a week off without the business noticing." |
| **Contrarian** | Goes against common advice, honestly | "Another tool won't fix a process nobody follows." |

Rules:
- The claim has to be true and something the user actually believes. Don't
  manufacture an opposing group to make a hook.
- Curiosity gaps pay off in the same post. No "more in the replies."
- Clear-outcome hooks can't promise results the user can't show.
- Write three hooks of different types per post and pick one.
- Keep the user's hook bank (in their context) up to date with winners.

## Packaging (Ryan: closer to 50/50 on packaging vs content)

- First line under about 12 words, no warm-up.
- Line breaks between thoughts. Scannable. A 10-year-old could follow it.
- One specific noun early (a tool, a missed call, a calendar link).
- Write for a smart outsider. Bier (Sep 2025): write "in a way that is
  accessible to broader audiences."
- Steal formats, not content, from adjacent niches.
- Links in the body with context; see the shared surfaces reference.

## Hook bank format

Store a user's hooks in their private context, tagged by type and mix:

```
N. **<Hook type> · <mix>** (confirm, if it describes a real moment)
   > <first line>
   > <second line>
```

Slots like `{{RESULT}}`, `{{CLIENT TYPE}}` and `{{REAL NUMBER}}` stay blank
until the user fills them with something true.
