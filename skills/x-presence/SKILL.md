# X profile and presence

Read [runtime](references/runtime.md), [surfaces](references/surfaces.md),
[privacy](references/privacy.md) and [presence](references/presence.md).

Work from what the user supplies (screenshot, current text). Without it, give
provisional recommendations and say nothing was inspected. Draft two or three
options per element in the user's voice. Count bio characters. Flag any
claim in a bio that the user should confirm. For a handle change, list the
checks in the reference and don't call a handle available without checking.

Start with the basics: a real face photo, a bio of 3 lines or less that
says what the user does, a simple header, and a bio CTA only when something
real sits behind the link. Treat the profile as the sales page: every element points to the same one
next step (`{{CTA}}`) the user's context allows. Return the checklist with a
status per item and the copy options. The user makes every change.
