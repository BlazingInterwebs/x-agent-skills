# Reply triage on your own posts

Answer every real reply in the first hour or two. Each answer is more
conversation on the post (reply weight 5.0), and a new post from a smaller
account may still be in its trial window (about 2 hours, INTERPRETATION of
code params).

| Bucket | What it is | What it gets |
| --- | --- | --- |
| **Question** | A real question, especially one many people share | A direct answer; consider a new post via `x-post` |
| **Substance** | Adds data, disagrees, extends | The most thoughtful answer on the thread |
| **Lead** | Describes the problem the user solves | A useful public answer; no hard pitch; private follow-up only if they ask |
| **Support** | Thanks, agreement, emoji | A short thanks, or a like by the user |
| **Bad faith** | Bait, insults, spam | Nothing; the user may mute or block (their call) |

Sort, then write in that order, and stop when the value stops. Never promise
a resource that doesn't exist. Mark unanswered factual questions for the user.
