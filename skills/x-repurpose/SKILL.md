# X repurposing

Read [runtime](references/runtime.md), [privacy](references/privacy.md),
[growth](references/growth.md) and [extraction](references/extraction.md).

Confirm the user may reuse the source. Extract standalone ideas, each with
its own hook and payoff. Write every version natively for X; don't paste
captions or video descriptions. Don't repost the same text. Return a short
list of briefs with format and hook type, and route chosen ones to `x-post`
or `x-longform`.
